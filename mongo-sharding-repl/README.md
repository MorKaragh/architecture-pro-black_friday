# Шардирование mongodb

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

через какое-то время должен подняться кластер mongodb и API, а в самой БД должны появиться данные.


## Как проверить

Откройте в браузере http://localhost:8080

Количество документов в шардах, а так же количество самих шардов, будет в выводе python-приложения, ничего дополнительно делать не нужно.
