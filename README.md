# Sprint 4 

- **`mongo-sharding/`** - Реализация шардирования MongoDB для горизонтального масштабирования
- **`mongo-sharding-repl/`** - Шардирование с репликацией для повышения отказоустойчивости
- **`sharding-repl-cache/`** - Полная архитектура: шардирование, репликация и кеширование
- **`diagrams/`** - Диаграммы архитектурных решений (варианты шардирования, репликации, кеширования, API Gateway, CDN)
- **`tasks_7_to_10/`** - Документация по заданиям 7-10: схемы коллекций, стратегии шардирования, мониторинг горячих шардов, использование реплик для чтения, миграция на Cassandra
